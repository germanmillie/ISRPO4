# Geometric_lib

## Общее описание
В проекте есть два файла:
- "circle.py" (для круга)
- "square.py" (для квадрата) 

Проект содержит четыре функции:
- Вычисление площади круга.
- Вычисление периметра круга.
- Вычисление площади квадрата.
- Вычисление периметра квадрата.

## Описание Функций
### circle.py

#### area( r )
Данная функция принимает значение радиуса " r " и по выражению " math.pi * r * r " возвращает площадь круга.

Пример вызова функции: 
```python
area(6)
```

#### perimeter( r )
Данная функция принимает значение радиуса " r " и по выражению " 2 * math.pi * r " возвращает периметр круга.
```python
perimeter(7)
```

### square.py
#### area( a )
Данная функция принимает значение стороны квадрата " a " и по выражению " a * a " возвращает площадь квадрата.
```python
area(8)
```

#### perimeter( a )
Данная функция принимает значение стороны квадрата " a " и по выражению " 4 * a " возвращает периметр квадрата.
```python
perimeter(8)
```

## План модульного тестирования

### 1. Цели и задачи тестирования

Цель тестирования — проверить правильность работы функций для вычисления площади и периметра круга и квадрата.

Для этого необходимо написать unit-тесты, проверить функции на разных входных данных и сравнить полученные результаты с ожидаемыми.

### 2. Описание тестируемого продукта

Для тестирования используется библиотека `geometric_lib`, написанная на Python. Она позволяет вычислять площадь и периметр геометрических фигур.

В библиотеке есть два основных файла:

- `circle.py` — функции `area(r)` и `perimeter(r)` для круга.
- `square.py` — функции `area(a)` и `perimeter(a)` для квадрата.

### 3. Область тестирования

В данной работе проверяются четыре функции:

- `circle.area`
- `circle.perimeter`
- `square.area`
- `square.perimeter`

Для проверки были созданы два файла:

- `test_circle.py` — 4 теста для круга.
- `test_square.py` — 7 тестов для квадрата.

Всего написано 11 тестов. Проверяются обычные, нулевые и дробные значения.

### 4. Стратегия тестирования

Для написания тестов использовался встроенный модуль Python `unittest`.

Все тесты находятся в классах, наследующихся от `unittest.TestCase`.

Для проверки результатов используются методы:

- `assertEqual` — проверяет точное равенство значений.
- `assertAlmostEqual` — сравнивает числа с учётом небольшой погрешности.

Для запуска всех тестов использовалась команда:

```bash
python3 -m unittest -v test_circle.py test_square.py
```

### 5. Критерии приёмки

Тестирование считается успешным, если все 11 тестов проходят без ошибок, а результаты вычислений совпадают с ожидаемыми.

Если хотя бы один тест не проходит, необходимо выяснить причину ошибки и повторить проверку.

### 6. Ожидаемые результаты

Ожидается, что все функции будут правильно вычислять площадь и периметр фигур на выбранных входных данных.

После успешного выполнения всех тестов в терминале должен появиться результат `OK`.
