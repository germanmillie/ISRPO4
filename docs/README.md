# Geometric_lib

## Общее описание
В проекте есть два файла:
- "circle.py" (для круга)
- "square.py" (для квадрата) 

Проект содержит четыре функции:
- Вычисление площади круга.
- Вычисление периметра круга.
- Вычисление площади квадрата.
- Вычисление периметра квадрата.

## Описание Функций
### circle.py

#### area( r )
Данная функция принимает значение радиуса " r " и по выражению " math.pi * r * r " возвращает площадь круга.

Пример вызова функции: 
```python
area(6)
```

#### perimeter( r )
Данная функция принимает значение радиуса " r " и по выражению " 2 * math.pi * r " возвращает периметр круга.
```python
perimeter(7)
```

### square.py
#### area( a )
Данная функция принимает значение стороны квадрата " a " и по выражению " a * a " возвращает площадь квадрата.
```python
area(8)
```

#### perimeter( a )
Данная функция принимает значение стороны квадрата " a " и по выражению " 4 * a " возвращает периметр квадрата.
```python
perimeter(8)
```
